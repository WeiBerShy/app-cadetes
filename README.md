# App de cadetes — Empaquetar

Descarga de la app de Android para los cadetes.

## Descargar

**[Bajar la última versión](https://github.com/WeiBerShy/app-cadetes/releases/latest/download/empaquetar-cadete.apk)**

Este link siempre baja la última versión (es el mismo del QR del área de cadetes).

## Cómo instalar

1. Abrí el link (o escaneá el QR) desde el celular.
2. Cuando termine de bajar, tocá el archivo `empaquetar-cadete.apk`.
3. Si Android avisa que no permite instalar apps de esta fuente, entrá a **Configuración**, habilitá **Permitir de esta fuente** para el navegador y volvé atrás.
4. Tocá **Instalar** (o **Actualizar** si ya la tenías). No hace falta desinstalar la anterior.
5. Entrá con tu usuario y contraseña de siempre.

Si tenés dudas, consultá con la oficina.
